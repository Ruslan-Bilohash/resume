### ✨ Що вміє цей проект

- ✅ **3 мови**: Українська 🇺🇦, Норвезька 🇳🇴, Англійська 🇬🇧  
- ✅ Повністю адаптивний дизайн (ідеально виглядає на телефоні)  
- ✅ Реєстрація та авторизація  
- ✅ Зручний редактор з акордеонами (спойлерами)  
- ✅ Прогрес-бар заповнення профілю  
- ✅ Live Preview резюме  
- ✅ Генерація PDF з вибором мови у красивому модальному вікні  
- ✅ Відправка PDF на **будь-яку** електронну пошту  
- ✅ Збереження всіх даних у JSON-файлах (1 користувач = 1 файл)  
- ✅ Завантаження фото профілю  
- ✅ Сучасний преміум-дизайн з анімаціями

---

### 🛠 Технології

- **Backend**: PHP 8+
- **Frontend**: Bootstrap 5, Font Awesome 6, html2pdf.js
- **Дані**: JSON файли (без бази даних)
- **PDF**: html2pdf.js + серверна відправка
- **Пошта**: PHP mail() з вкладенням

### 🚀 Як запустити локально

1. Склонуй репозиторій:
   ```bash
   git clone https://github.com/Ruslan-Bilohash/resume.git
   ```

2. Створи дві папки в корені проекту:
   - `users/`
   - `uploads/`

3. Дай їм права на запис (755 або 777)

4. Відкрий проект у браузері — все готово!
